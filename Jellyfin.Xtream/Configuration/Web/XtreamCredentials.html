Display names

Names of the folders shown in Jellyfin. Leave empty to keep the default name. Renaming a folder creates a new one: watch progress kept in the old folder is lost.

Category folders

One folder per line: Name: KEY1, KEY2. A category goes into the first folder with a key equal to one of its tags (|FR|, [EN]) or present as a word in its name. Inside a folder, tags are removed from the category names. Leave empty to list the categories as the provider sends them.
